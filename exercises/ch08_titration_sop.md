# 第 8 章 滴定 SOP（可列印）

目的：用 NaOH 滴定量出醋的酸度（w/v %），並且**自己標定 NaOH 的力價**，把「未標定力價」這個比例誤差去掉。
紀錄表：`ch08_titration_sheet.csv`（KHP 3 份、空白 2 次、原液 3 次、盲樣 A–D 各 3 次，共 20 列）。

> 器材允差、重複判定門檻都是**建議值**，請依你手上的器材與老師的要求調整。

## 0. 準備

- 50 mL 滴定管、10 mL 吸量管（或 5 mL、20 mL，見第 3 節）、25 mL 吸量管、100 mL 容量瓶、錐形瓶、酚酞指示劑。
- NaOH 約 0.1 N（稱重配製即可，**不必**追求剛好 0.1000，因為要標定）。
- KHP（鄰苯二甲酸氫鉀，M = 204.22 g/mol，一級標準，使用前 105 °C 烘乾冷卻）。

## 1. 標定 NaOH（KHP，3 份）

1. 秤 KHP **約 0.41 g**（20 mL 的 0.1 N NaOH 需要 0.1 × 0.020 × 204.22 = 0.4084 g），記錄**實際**秤重到 0.1 mg，填入紀錄表「秤重_g」。
2. 溶於約 50 mL 純水，加 2 滴酚酞，用 NaOH 滴到**淡粉紅色維持 30 秒**。
3. 記錄滴定管**起點**與**終點**讀數（讀到 0.01 mL），用量 = 終點 − 起點。
4. 力價 f = m / (204.22 × 0.1 × V / 1000)，m = KHP 克數、V = NaOH 用量（mL）。
5. 3 份各算一個 f，報告 **平均 ± 標準差**，並寫明力價是怎麼得到的（標定日期、KHP 份數）。

## 2. 空白（2 次）

1. 約 25 mL 純水 + 2 滴酚酞，滴到同樣的淡粉紅色。
2. 記錄用量，取平均當**空白用量 V_blank**（通常很小，但要量）。

## 3. 稀釋的選擇：讓滴定量落在 15–40 mL

稀釋步驟：取 D mL 醋 → 100 mL 容量瓶定容 → 取 25 mL 滴定。**D 越大，滴定量越大。**
滴定量太小，讀數誤差佔比大；超過 50 mL 要重裝滴定管。下表是 f = 1.07875 時的預估滴定量（mL）：

| 酸度 (%) | D = 5 mL | D = 10 mL | D = 20 mL |
|---|---|---|---|
| 3 | 5.8（太小） | 11.6（太小） | **23.2** |
| 5 | 9.7（太小） | **19.3** | **38.6** |
| 7 | 13.5（偏小） | **27.0** | 54.1（超過 50） |
| 11.39 | **22.0** | 44.0（偏大） | 88.0（超過 50） |

粗略的選法：低酸度（約 3 %）用 D = 20 mL；中酸度（5–7 %）用 D = 10 mL；高酸度（約 11 %）用 D = 5 mL。
原液酸度不知道時，先用 D = 10 mL 試滴一次，再依第一次的用量調整 D。

## 4. 樣品滴定（原液、盲樣 A–D，各 3 份）

1. 依第 3 節取 D mL 樣品定容到 100 mL，混合均勻，取 25 mL 到錐形瓶，加 2 滴酚酞。
2. 滴到淡粉紅色維持 30 秒，記錄**起點、終點**讀數與用量。
3. 每個樣品做 **3 次重複**。若 3 次之間最大與最小差超過約 **0.10 mL**（建議規則），先檢查操作，再**補做一次**；不要直接丟掉不順眼的那一筆。
4. 盲樣由別人編碼，操作者不知道濃度，**不要**依濃度大小排順序。

## 5. 計算

酸度 (w/v %) = (V − V_blank) × f × 0.006 × (100 / 25) × (100 / D)

- V：樣品的 NaOH 用量（mL）；V_blank：空白用量（mL）；f：第 1 節的力價。
- 0.006 g/mL：每 mL 0.1 N NaOH 對應的醋酸克數（精確值 0.1 × 60.05 / 1000 = 0.006005，差 0.08 %，可忽略）。
- 100/25：定容後只取 25 mL 滴定；100/D：D mL 醋稀釋到 100 mL。D = 10 mL 時就是 ×10。

範例（D = 10 mL，f = 1.07875，V_blank = 0）：V = 17.0 mL → 17.0 × 1.07875 × 0.006 × 4 × 10 = 4.40 %。

## 6. 報告

- 每個樣品：3 份酸度的**平均 ± 標準差**。
- 力價：f 的平均 ± 標準差（KHP 3 份）與標定方法。
- 註明單位是 w/v %，Atago（ATAGO PAL-Easy ACID）是以導電度為基礎的酸度計，**不是折射計**，兩種方法的讀值不一定相同。
- 若與標示或 Atago 差很多：先看是否為比例性（所有樣品同方向、同比例，可能是力價）還是個別樣品（可能是操作或樣品），**重測**後再下結論。
