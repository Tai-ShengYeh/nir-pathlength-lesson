# 第 7 章 實驗計畫與紀錄表（可列印，一頁）

配合 `ch07_run_sheet.csv`（共 49 列：預試驗 13 列 + 主實驗 24 列 + 驗證 12 列）。實驗前把計畫與分析方法寫好，實驗後不要再改。

## 1. 預試驗（先做，13 次掃描）

- [ ] 同一瓶約 4 % 的醋，**重新填樣 10 次**（填樣 1–10，每次掃描 1 次）：看填樣造成的標準差 s_fill。
- [ ] 再做**第 11 次填樣**，對它連續掃描 3 次（填樣 11、掃描 1–3）：看純粹的掃描雜訊（掃描雜訊檢查，不與前 10 次重複）。
- [ ] 算出 s_fill，並用第 3 節的因子得到真 σ 的 95 % 範圍（10 次：約 0.69–1.83 倍 s）。
- [ ] 若 s_fill 比預期大很多，先找原因（氣泡、填樣量、擦拭比色槽），再進主實驗。

## 2. 標準品（主實驗用的 8 個濃度）

- [ ] 原液先**滴定 3 次**，記下平均濃度與每次的滴定體積。
- [ ] 以**秤重稀釋**配出 0–7 % 共 8 個濃度（0、1、2、3、4、5、6、7 %），記下每瓶秤重數字。
- [ ] 每個濃度配一瓶，標上瓶號；同一濃度的 3 次填樣共用這一瓶。

## 3. 主實驗（8 濃度 × 3 次填樣 = 24 次掃描，分 3 區塊）

- [ ] 依順序表的「順序」逐列進行；每塊 8 個濃度各 1 次，3 塊的順序不同（拉丁方式輪替）。
- [ ] 每次都**重新填樣**，掃描 1 次，不要連續重複掃同一次填樣來當重複。
- [ ] 每一列即時填：日期、操作者、光徑_mm、瓶號、溫度_C、檔名、備註（氣泡、異常、延遲等）。
- [ ] 不要為了「趕進度」改順序；順序被打亂就在備註欄寫下原因。

## 4. 驗證（盲樣，12 次掃描）

- [ ] 4 個盲樣（順序表的盲樣A–盲樣D）由**別人**編碼、配好，**操作者不知道濃度**（順序表的濃度欄留空）。
- [ ] 每個盲樣填樣 3 次，順序表依輪替排：A1 B1 C1 D1 ／ B2 C2 D2 A2 ／ C3 D3 A3 B3（字母＝盲樣，數字＝第幾次填樣）。
- [ ] 每個盲樣的參考值：**滴定 3 次**，取平均。
- [ ] 用主實驗建立的校正預測盲樣，**預測完才看滴定結果**。
- [ ] 報告：預測值與滴定值比較的 **RMSEP**（預測均方根誤差）與**平均偏差**（預測 − 滴定，看有沒有系統性偏高或偏低）。
- [ ] 次要記錄：預測區間是否涵蓋滴定值（僅供參考，樣品只有 4 個，涵蓋率不是主要結論）。

## 5. 紀錄欄位（順序表空白欄）

| 欄位 | 說明 |
|---|---|
| 日期、操作者 | 誰、哪天量的 |
| 光徑_mm | 比色槽實際光徑 |
| 瓶號 | 對應的標準品或盲樣瓶 |
| 溫度_C | 量測時室溫或樣品溫度 |
| 檔名 | 儀器存檔檔名，與列一一對應 |
| 備註 | 氣泡、異常、順序變動、重測原因 |

## 6. 分析方法事先定好（實驗前簽名，實驗後不改）

- [ ] 二階導數：Savitzky–Golay 9 點、二次多項式；取 2258 nm。
- [ ] 校正：反向校正 y = a + b·c，用滴定值當參考；報告斜率、殘差 s、s/|b|。
- [ ] 線性檢查：缺適性檢定（8 濃度 → lof_df 6，純誤差 df 16）。
- [ ] 預測區間：Fieller 區間；同一濃度的 3 次填樣共用配製誤差，改用 8 個濃度平均（自由度 6）。
- [ ] 離群規則（同第 6 章）：先定規則、同類相比、找原因、重測、含與不含兩種結果都報告。
