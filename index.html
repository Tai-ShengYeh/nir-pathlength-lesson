ORANGE · PYTHON · R

近紅外光譜：醋酸定量與最佳光徑

用一台 NeoSpectra 實測的醋酸光譜，從「光徑要選多長」一路學到參考值、波長挑選的陷阱，以及 PCA 與 PLS。每章都有配音動畫、隨堂小測驗，以及可以自己跑、自己對答案的練習。

▶ 開始上課 學生講義 Orange 練習總覽 ⬇ 全部教學包

怎麼學

1　看動畫

每章 7–9 分鐘，有旁白；做完隨堂小測驗再往下。

2　動手做

下載教學包，用 R、Jupyter／Colab 或 Orange 重算一次。

3　對答案

R 與 Python 練習會自動比對答案，全部 PASS 才算完成。

章節

開始之前

教學包解壓縮後請保留資料夾結構（exercises/、data/），練習程式與 Orange 工作流程都是用相對路徑找資料。
R 只用內建套件；Python 需要 numpy、pandas、scipy、matplotlib；Colab 版不用安裝，資料已內嵌。
Orange 請安裝 Orange Data Mining，再從 Options → Add-ons 加裝 Spectroscopy 外掛（測試版本 3.40.0）。
